# homebrew-scout

Homebrew tap for [scout](https://github.com/daniel13112001/scout), a local
semantic search CLI.

## Install

```
brew install daniel13112001/scout/scout
```

## Updating the formula

After a new scout release is tagged and published on
[daniel13112001/scout](https://github.com/daniel13112001/scout/releases):

```
scripts/bump.py v0.1.0
git commit -am "scout v0.1.0"
git push
```
